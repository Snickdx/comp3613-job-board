# Actor Notes

## Primary Actors

### Graduite Applicant
- create/ update profile
-  upload/ update resume
-  select preferences
-  subscribe to notifications
-  recieve notifications
-  apply to job listings
-  check application status 
- send/recieve messages


### Employer
- create/ update profile
-  create/ update job listings
-  apply for listing approval
-  accept/decline job applicaitons
-  send/recieve messages
-  recieve notifications


### Admin
 - review and approve/ decline job listing requests
 -  send/recieve messages
 -  recieve notifications
 -  manage student notifications
